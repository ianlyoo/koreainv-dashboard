# Android 인사이트 간격·색상 정리 · v1.9.8

2026-09-09 · 사용자 화면 검토 후 승인 · 필수 업데이트 · Android versionCode 42

## 변경 사항

- 재무의 제목, 차트, 선택 분기 수치, 상세정보 펼침 행 사이 간격을 정돈했다.
- 애널리스트의 종합 의견, 투자의견 분포, 목표가 범위를 구분하고 정보 묶음 사이에 20dp 간격을 적용했다.
- 옵션은 구성 비율, 동일 시각 평균 대비, 만기와 주요 가격, 감마 노출을 24dp 간격으로 구분했다. 콜·풋은 같은 행의 양쪽에 배치하고, 비교 누적 거래량 행에도 동일한 12dp 간격을 적용했다.
- 차트와 가격 범위 표시를 기존 앱의 초록·빨강 색상으로 통일했다. 목표가 범위와 평균 지점은 초록의 농도와 도형으로 구분한다.
- 접기·펼치기, 분기 선택 등 조작 요소는 파란색을 사용한다. 하단 탐색의 중립색과 데이터 기준 시점의 기본 접힘은 유지한다.
- 값의 계산·정밀도, 데이터 연결·인증, 차트 선택 동작은 변경하지 않았다.

정보 위계와 정렬은 [Apple HIG의 Layout 지침](https://developer.apple.com/design/human-interface-guidelines/layout)을 참고했다. 기존 앱의 글꼴과 유리 효과를 사용하며 장식용 카드나 애니메이션을 추가하지 않았다.

## 검증

- API 35 에뮬레이터, 360dp 화면의 라이트·글꼴 100% 및 다크·글꼴 150%에서 세 섹션의 간격·정렬·색상을 확인했다.
- 분기 선택 후 수치 변경, 분기 상세정보 펼치기·접기를 확인했다. 검증 중 크래시 로그가 없었다.
- Android 단위 테스트 192개와 최종 Debug·R8 Release 빌드가 통과했다.
- 이전 화면과 수정 화면의 실제 앱 캡처는 로컬 `build/insight-spacing-review/`에 보관한다. 캡처는 오프라인 예시 데이터를 사용하며 배포 파일에 포함하지 않는다.
- 최종 세 플랫폼 배포 빌드, APK 버전·서명 인증서, 배포 파일 체크섬과 필수 업데이트 정책 검증 결과는 릴리스 기록에 정리한다.
