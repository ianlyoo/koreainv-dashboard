# Android 종목 인사이트 구현·검증

대상: v1.9.6 · 2026-09-09 · [승인 사양](android-stock-insight-implementation-proposal.md)

## 구현

- 보유 상세의 `종목 인사이트`에서 독립 실행하는 네이티브 화면을 연다. 미국 주식을 지원하며 PC 서버가 필요하지 않다.
- 가격 일봉·거래량과 개요, 분기 매출, 애널리스트, 옵션, 내부자, 뉴스를 제공한다. 정확한 값과 제공 목록을 펼칠 수 있다. 공급원·갱신·스냅샷 시각은 마지막 영역에 통합한다.
- `설정 → 연결 → SaveTicker`에서 계정을 연결한다. 미연결 상태로 인사이트를 누르면 안내와 함께 연결 설정으로 이동하고, 연결 완료 후 선택한 종목으로 돌아간다.
- 저장 기본값은 꺼짐이다. 선택 시 Android Keystore에 암호화하며 기기 화면 잠금이 필요하다. 쿠키는 메모리에만 둔다. 백그라운드 이동 시 앱 PIN 잠금과 요청 취소를 수행한다.
- 기기 저장소 정리 실패가 증권 계좌의 PIN 해제를 막지 않게 한다. 만료 또는 완료되지 않은 인증 기록은 다음 실행에서 다시 연결하도록 처리한다. 진행 중인 요청에서 프로세스가 종료되면 저장을 선택했어도 재연결이 필요할 수 있다.

## 저사양 대응

메모리 부족 기기, 힙 등급 128MiB 이하, 전체 메모리 3GiB 이하 또는 Android 11 이하에서는 라이브 배경 기록·블러·굴절을 사용하지 않고 대비가 유지되는 정적 유리 표면을 사용한다. 데이터와 기능은 동일하다.

PIN의 PBKDF2 강도는 유지하면서 암복호화 계산을 UI 스레드 밖으로 옮겼다. 인사이트는 최대 3개 endpoint를 동시에 조회하고 주기적으로 재조회하지 않는다. 캐시는 기본 8종목, 제한된 기기에서 4종목이며 메모리 압박·잠금·연결 해제에 맞춰 비운다. 증권 계좌 조회도 3개 또는 2개로 제한하며 취소가 실제 HTTP 응답 본문 읽기까지 전달된다.

차트 계산은 데이터·기간 변화에 맞춰 캐시하고 선택값 변경이 전체 화면의 구성·배치를 다시 수행하지 않게 한다. 긴 목록은 LazyColumn에서 필요한 행만 구성한다. 작은 높이의 화면에는 176dp, 그 외에는 216dp 가격 차트를 사용한다.

배포 빌드에 R8과 리소스 축소를 적용하고 사용하지 않는 Retrofit·원격 글꼴 의존성을 제거했다. Gson은 직접 의존성으로 관리하며, 저장된 증권 계정 JSON의 필드 이름을 보존하는 규칙을 추가했다. JSON은 엄격한 구문·중첩 깊이·응답 크기 제한을 적용한다. [Gson 공식 릴리스](https://github.com/google/gson/releases), [Android R8 문서](https://developer.android.com/topic/performance/app-optimization/full-mode)

## 측정과 실제 연결

API 31 ARM64 에뮬레이터, **실제 할당 2GiB·2코어**, SwiftShader, 동일한 디버그 앱의 오프라인 포트폴리오에서 탭 24회·스크롤 12회를 비교했다. 1GiB를 요청했지만 시스템 이미지가 2GiB로 자동 상향한 것을 로그로 확인했다.

| 측정값 | v1.9.5 기준 빌드 | 최적화 빌드 |
| --- | ---: | ---: |
| 프레임 시간 중앙값 | 21ms | 17ms |
| 프레임 시간 90백분위 | 40ms | 25ms |
| 프레임 시간 95백분위 | 48ms | 38ms |
| 작업 후 PSS 표본 | 95,918KiB | 109,972KiB |

이 짧은 에뮬레이터 비교는 실기기 FPS 보장이 아니다. PSS 감소는 관측되지 않았다. 디버그 코드·JIT·측정 시점 영향이 포함되므로 메모리 개선 수치로 제시하지 않는다. GPU 시간과 일부 jank 지표는 에뮬레이터에서 유효하지 않아 결론에 사용하지 않았다.

배포용 APK는 이전 릴리스의 약 12.69MB에서 로컬 축소 빌드 약 4.89MB로 감소했다(약 61.5%, 서명·메타데이터에 따라 최종 파일 크기는 소폭 달라짐).

실제 Android API 26·31 런타임에서 새 앱의 데이터 계층으로 로그인 후 AVGO와 AAPL을 각각 조회했다. 두 환경 모두 7개 정보 섹션과 일봉이 정상이며 종목별 252개 봉을 수신했다. 관측 날짜 범위는 2025-09-08~2026-09-08이다. 인증 정보는 호스트 보안 저장소에서 메모리로 읽어 로컬 검증 프로세스에 전달했으며 APK·기기 파일·인자·로그에는 넣지 않았다. 종료 시 메모리 인증 정보 제거를 확인했다.

## 검증 범위

- Android 단위 테스트: 188개 통과. 파싱·단위·누락/0·응답 제한·요청 병합·쿠키 갱신·취소·만료 후 재실행·캐시·표현을 포함한다.
- API 26·31 기기 검사: 환경마다 6개 통과. 실제 Keystore 왕복·암호문 확인·키 소실·미완료/만료 기록 거부, PIN 계산 중 UI 프레임 진행, PIN 제출 중 백그라운드 이동 후 재잠금을 확인한다.
- API 35·4GiB 환경에서도 위 6개 검사와 유리 효과가 켜진 화면 전환 검사를 통과했다(7개). 정적 효과가 적용되는 구형 환경과 라이브 효과 환경을 모두 확인했다.
- 축소된 릴리스 APK를 Android 8에 설치해 합성 계정 저장과 프로세스 재시작 후 PIN 재진입을 확인했다. 서명된 CI APK에서 기존 저장 모델 5개의 필드 22개가 유지되는 것을 DEX로 검사했으며 이전 릴리스와 서명 인증서가 동일하다.
- 데스크톱: 174개 테스트 통과. 인증 선행, 세션 분리·폐기, 중첩 필드 허용 목록, 저장·이전 실패 처리를 검증했다. 로컬 Keychain 이전은 두 기존 dotenv 항목 제거·나머지 설정 보존·저장 후 재조회 일치를 확인했다.
- macOS 패키지: 빌드·서명 검증, 실제 실행 상태 endpoint 200, 미인증 인사이트·연결 endpoint 401, Keychain 모듈 포함을 확인했다.
- Windows와 macOS 릴리스 작업에는 별도의 합성 OS 비밀 항목 저장·재조회·삭제 검증을 포함한다. 실제 사용자 항목은 건드리지 않는다.
- 세 플랫폼의 사전 릴리스 빌드와 두 데스크톱 OS 저장소 검사가 통과했다. APK/ZIP 및 두 데스크톱의 내장 Python 모듈을 검사해 실제 로그인 정보와 로컬 `.env`가 포함되지 않은 것을 확인했다.

물리적 저사양 휴대폰, 모든 제조사별 절전 정책, 모든 시장·종목, 수정주가 정책을 검증한 것은 아니다. Android 기기 검증과 실제 연결은 에뮬레이터에서 수행했다. 일봉을 실시간 분봉으로 표시하지 않는다.

검증 로그·캡처·계정 없는 요약은 로컬 `build/android-insight-performance/`와 `build/android-insight-runtime-probe/`에 보관하며 배포 파일에 포함하지 않는다.
