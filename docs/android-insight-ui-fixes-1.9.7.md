# Android 인사이트 UI 수정 · v1.9.7

2026-09-09 · 필수 업데이트 · Android versionCode 41

## 변경 사항

- 설정의 SaveTicker 연결 행에서 버튼 모양에 의해 제목과 설명이 잘리는 문제를 수정했다. 화면이 좁거나 글꼴 배율이 크면 연결 상태를 설명 아래에 배치한다.
- 핵심 지표, 가격 범위·거래 현황, 분기 매출, 애널리스트 평가, 내부자 거래의 펼침 행을 같은 시작선과 오른쪽 화살표로 통일했다. 전체 행을 누를 수 있고 터치 높이는 최소 48dp다. 접근성 서비스에 접힘/펼침 상태를 전달한다.
- 인사이트 하단 탐색의 선택·미선택 글자색을 각각 기본 글자색과 보조 글자색으로 변경했다.
- 데이터 기준 시점을 기본 접힘으로 변경했다. 펼치면 조회·현재가·핵심 지표·재무·애널리스트·옵션·내부자·뉴스·일봉별로 공급원, 상태, 기준 시각을 정렬해 표시한다. 좁은 화면이나 큰 글꼴에서는 이름과 값을 위아래로 배치한다.
- 기준 시각은 날짜와 시간을 나누어 표시하며 원래 시간대와 소수 초 값을 보존한다. 날짜만 제공된 값에 시각을 추가하지 않는다. 스냅샷·배치의 전일 여부와 잠정 집계 정보도 유지한다.

## 검증

- Android 단위 테스트 192개 통과. 시간대·날짜·원본 출처 보존, 옵션 기준 정보, 기본 접힘 및 펼침 목록 키를 검증했다.
- Debug APK, 기기 테스트 APK, R8 축소 Release APK 빌드 통과.
- Python 테스트 174개와 하위 검사 19개 통과.
- API 35 에뮬레이터의 360dp 화면에서 라이트·기본 글꼴과 다크·글꼴 150%를 확인했다. SaveTicker 제목·설명·연결 상태가 잘리지 않고 연결 설정으로 이동한다. 상세정보 행의 시작선과 화살표 정렬, 펼치기·접기, 하단 탐색의 중립 글자색, 데이터 기준 시점의 기본 접힘과 펼친 값 정렬을 캡처와 UI 계층으로 확인했다. 크래시 로그는 없었다.
- 오프라인 합성 데이터를 사용하며 캡처·로그는 로컬 `build/v1.9.7-ui/`에 보관하고 배포 파일에 포함하지 않는다. 최종 배포 빌드와 산출물 검증 결과는 릴리스 기록에 정리한다.

v1.9.6의 연결·보안·성능 검증 범위는 [기존 검증 기록](android-insight-validation.md)을 참고한다.
