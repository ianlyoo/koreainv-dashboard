Overview

Korea Investment Securities dashboard — track portfolio and market monitoring with Google Sheets ops integration in live trading workflows.

Repository: https://github.com/ianlyoo/koreainv-dashboard — Pages: https://ianlyoo.github.io/koreainv-dashboard/ — Language: Python — License: MIT

README (English) — README (한국어)

Features

  • Portfolio tracking: Holdings, balances, PnL vs KIS Open API
  • Market monitoring: Real-time quotes and watchlists
  • Google Sheets ops: Export and sync
  • Launcher + updater: Cross-platform launchers

Quick start

git clone https://github.com/ianlyoo/koreainv-dashboard.git
cd koreainv-dashboard
pip install -r requirements.txt
cp .env.example .env
python launcher_windows.py

See Windows install guide in README_INSTALL_WINDOWS.md
