# Android 종목 인사이트 디자인 시안

검토용 HTML 프로토타입. 제품 코드 변경, 인증, 네트워크 조회, 저장, 배포는 구현하지 않았다. 모든 숫자·기관·뉴스·거래는 가상 예시이며 실제 분석에 사용할 수 없다.

## 권장 방향

**Visual thesis:** 현재 Android의 어두운 바탕과 유리 헤더 위에서, 가격 차트를 첫 시각 기준으로 삼고 구분선과 타이포그래피로 분석 정보를 연결하는 종목 상세 화면.

**Content plan:** 가격 차트 → 정렬된 선택 일봉 수치 → 현재가·기업 → 개요 지표 → 분기 실적 → 애널리스트 의견과 목표가 → 옵션 구성·평균 대비·가격 수준·GEX → 내부자 제공 목록 → 뉴스 → 통합 데이터 기준 시점. 화면 아래에는 섹션 탐색 유리 캡슐을 고정한다. 보유 상세의 `종목 인사이트`가 진입점이며 기존 메인 하단 내비게이션과 중복하지 않는다.

**Interaction thesis:** 상세 진입 220ms, 스크롤 아래 내용이 비치는 헤더와 고정 섹션 이동, 상세 수치 공개 180ms. `prefers-reduced-motion`에서는 모두 제거한다.

## 검토 방법

저장소 루트에서 다음 명령으로 열 수 있다.

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory design/android-insight
```

주소: `http://127.0.0.1:8772/`

1. 차트 우선 위계와 정렬된 일봉 수치를 확인한다. 시세·일봉·각 섹션의 기준 시각은 맨 아래에서 확인한다.
2. 기간 버튼을 누르면 같은 가상 표본의 1/3/6/12개월을 날짜로 잘라 표시한다. 약 1년의 합성 평일 표본이며 생산용 미국 휴장 달력은 적용하지 않았다. 마지막 일봉 9월 4일 $316.15와 9월 8일 시세 $320.40을 구분한다.
3. 차트를 누르거나 이전/다음 버튼을 사용하면 해당 점의 날짜와 OHLC와 거래량이 표시된다. 캔들/라인을 바꾸어도 선택점이 유지된다.
4. 각 섹션으로 이동하고 분기 4개, 리서치 6개, 옵션 원수치, 내부자 4개 전체 행을 펼친다. 수치 표는 차트의 텍스트 대안이다.
5. 부분 성공에서는 옵션 영역만 정보 없음으로 전환한다. 만료에서는 모든 인사이트를 숨기고 재연결을 안내한다. 오프라인에서는 상단 상태 안내와 통합 시점 영역의 원래 기준 시각이 유지된다. 다시 시도는 외부 호출 없이 검토용 상태 유지 안내를 표시한다.
6. 만료 → 연결 다시 확인 → 고정 DEMO 폼 → 연결 다시 확인 → 뒤로. 연결 정보 저장 토글은 메모리에만 존재하며 새로 로드하면 꺼진다.
7. 외부 검토 도구에서 보유 상세로 이동하고, 인사이트 진입 후 뒤로를 눌러 스크롤이 복원되는지 확인한다.
8. 다크/라이트, 휴대폰/전체 길이 보기, 좁은 브라우저 폭, 키보드 Tab/Enter/Space를 확인한다.

## 상태 및 보안 경계

- HTML에는 사용자 자격정보를 입력할 수 있는 필드가 없다. 두 필드는 고정된 DEMO 문자열의 readonly 일반 텍스트이며 autocomplete가 꺼져 있다.
- fetch/XHR/WebSocket, 외부 스크립트·폰트·이미지·링크, localStorage/sessionStorage/cookie/IndexedDB가 없다. 상태는 JavaScript 메모리에만 있다.
- 연결/해제/캐시 삭제는 알림과 UI 상태의 모의 동작이다. 캐시/비밀정보 저장 자체가 없고, 가상 fixture는 지워지지 않는다.
- 제품 문구인 `기기의 보안 저장소에 보호됩니다`는 향후 제품 동작 제안이다. 이 HTML은 해당 보호를 구현하지 않는다.
- 제안된 실제 정책: 연결 정보 저장은 기본 꺼짐. 기기 화면 잠금이 설정된 경우에만 Android Keystore와 백업 제외 영역에 저장하고 앱 PIN을 통해 접근. 백그라운드 진입 시 자동 잠금, 외부 뉴스에서 복귀하면 PIN 확인. 구체 계약은 부모 작업의 보안·구현 계획을 따른다.

## 검증과 한계

- `node --check design/android-insight/app.js` 통과.
- 외부 통신·저장 호출 없이 정적 파일 및 메모리 상태로 동작하도록 코드 확인.
- 이전/다음 점 범위는 clamp, 기간 변경 시 끝점으로 재설정. 선택점이 짧아진 데이터 범위를 벗어나지 않는다.
- 브라우저 실제 시각 QA 완료: 다크/라이트와 연결 화면 캡처, 차트 선택·기간·선 전환·섹션 이동·펼침·부분 성공·오프라인·만료·연결/해제·뒤로가기 16개 확인 통과. 360px에서 모든 펼침과 글자 150% 확대 시 가로 넘침 없음. Android Compose, TalkBack, 큰 글꼴, 실제 네트워크 경합·잠금 복원·Keystore 검증은 이 시안의 검증 범위 밖이다.
- 정적 가상 시계열에는 거래일/휴장 검증이 없다. 실제 데이터 계약의 조정주가, 휴장, 결측, 표본 수를 표현하는 생산용 차트가 아니다.
- 가상 리서치 6개 목표가 평균은 정확히 $350이며 표시된 상승 여력은 $320.40 대비 +9.24%. 모든 비교 수치는 fixture 기준이다.

## 계약 정렬 보완

개요는 시가총액과 key_metrics의 PER/EPS/분기 매출/배당/ROE/공매도 비중/상환 소요일 8개 항목으로 구성한다. 재무는 제공 계약에 맞춰 분기 매출과 YoY만 표시한다. 옵션은 d3/d7/d30 동일 시간대 거래량 비교와 100% 기준선(available=true fixture)을 사용하고 풋/콜 PCR, 만기/맥스페인/콜월/풋월/감마전환/GEX를 분리한다. 옵션 잠정 기준시각을 표기한다. 내부자 기간 집계와 제한된 최근 목록은 독립적으로 표시하고 목록은 이름/역할/거래일/유형/금액만 사용한다. 애널리스트는 이전/현재 목표가 및 현재가 위치를 제공한다.

독립 휴대폰 보기: `?phone=1`. 검토 도구를 숨기고 외부 예시 데이터 배너만 유지한다.

개요의 `revenueTtm`은 관측된 분기 계약에 맞춰 분기 매출로 표시한다. 가격 범위·거래 현황 펼침, 거래량/OI PCR, 전일 스냅샷과 배치, 1% 변화당 감마를 포함한다. 정확한 값 표는 14px이며 목표가와 현재가 표식은 같은 280–380 USD 선형 범위에 놓인다. 가격 축은 선택 기간의 최저/최고 범위로 계산한다.

최종 시안은 애널리스트의 긴 행을 기관별 라벨-값 목록으로 표현한다. 로컬 서버는 디자인 디렉터리만 제공한다. 검증 캡처는 저장소의 `output/playwright/android-insight-*.png`에 있다.

## 수정 02 — 시점 통합과 유리 탐색 바

시각 방향은 데이터 본문을 단정하게 비우고 상단·하단에만 부유하는 유리 캡슐을 두는 것이다. `LiquidGlass.kt`의 투명 표면, 얇은 하이라이트, 34dp 곡률과 기존 하단 선택 캡슐에 맞춘다. CSS blur/saturation은 네이티브 lens 효과의 근사다.

선택 일봉 날짜/탐색을 한 행에 두고 시가·고가·저가·종가는 같은 폭의 네 열에 배치한다. 거래량은 라벨과 우측 수치로 정렬한다. 본문에 반복하던 공급원·스냅샷/배치 시점은 뉴스 뒤 `데이터 기준 시점` 12개 행으로 통합한다. 평가일·거래일·기사 발행일·분기 축·선택 일봉 날짜는 데이터 자체의 의미이므로 각 행에 유지한다.

상단 유리 헤더는 스크롤 시 고정, 하단 유리 캡슐은 화면 아래 고정한다. 활성 섹션의 둥근 선택 표면과 누름 피드백은 180ms이며 축소 모션에서는 제거한다. 본문 끝 여백으로 바가 마지막 행을 가리지 않게 한다. 부분 실패 상태에는 실패한 옵션의 기준 시각을 정상값처럼 표시하지 않는다.

## 수정 03 — 보유 상세 진입부와 기간 버튼

보유 상세의 인사이트 진입부는 다른 섹션과 같은 20px 제목·14px 보조 설명·왼쪽 정렬·24px 세로 여백을 적용한다. 제목은 본문 기본색, 오른쪽 이동 표시는 48px 유리 원형 조작부로 표현한다. 차트 기간 선택은 그룹을 감싸던 배경과 패딩을 제거하고 선택된 기간만 강조한다.

## 수정 04 — 연결 설정 흐름과 선택 상태

인사이트 진입 화살표는 원형 배경·테두리 없이 `>`만 표시한다. 행 전체의 터치 영역은 유지한다. 기간 그룹 배경은 계속 비우고 선택된 기간의 원형 표면에만 상·하단 바와 같은 Liquid Glass 재질을 적용한다.

연결 설정 진입점은 보유 상세에서 제거하고 `설정 → 연결 → SaveTicker`로 옮긴다. 검토 도구의 화면 목록에 설정 루트와 연결 설정 상세를 나누고, 데이터 상태에 `미연결`을 추가한다. 보유 상세에서 미연결 상태로 인사이트를 선택하면 지속적인 안내 문구와 함께 연결 설정으로 이동한다. 모의 연결 성공 시 원래 인사이트로 돌아가며, 취소하면 보유 상세로 돌아간다. 설정에서 직접 열었을 때의 뒤로가기는 설정 루트를 복원한다.

연결 설정은 동일한 유리 헤더, 20px 섹션 제목, 20px 본문 여백, 구분선 기반 입력 행, 유리 연결 버튼을 사용한다. 연결된 계정은 상태와 관리 항목을 표시하고, 미연결 상태는 읽기 전용 예시 폼을 표시한다. 저장은 기본 꺼짐이며 실제 인증이나 자격정보 저장을 수행하지 않는다.
